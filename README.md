# 🎵 Music Player

A modern and responsive music player built with HTML5, CSS3, and Vanilla JavaScript. It allows users to play songs, control playback, view song information, adjust volume, and navigate through a playlist with a clean and interactive interface.

## 🚀 Live Demo

Explore the live site: https://aamina-naleem.github.io/CodeAlpha_MusicPlayer/

## ✨ Features

• Play and pause music with interactive controls.
• Previous and Next buttons for playlist navigation.
• Displays song title, artist, current time, and duration.
• Interactive progress bar for controlling playback position.
• Volume control for adjusting audio levels.
• Playlist functionality for managing multiple songs.
• Autoplay feature for continuous playback.
• Responsive design for mobile, tablet, and desktop screens.

## 🛠️ Technologies Used

• HTML5
• CSS3
• Vanilla JavaScript (ES6+)
• HTML5 Audio API
• Remix Icons
